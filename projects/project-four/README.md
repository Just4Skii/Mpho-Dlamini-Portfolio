# Project Four — Future Application Slot

This slot is reserved for future independent React frontend applications.

## Integration Process:
1. Place project files into `projects/project-four/`.
2. Configure `base: mode === 'production' ? '/work/project-four/' : '/'` in `vite.config.ts`.
3. Add to root `package.json` workspaces.
4. Add copy step in `assemble-dist.js`.
5. Update `portfolio/src/config/projects.ts`.
6. Run `npm run build`.
